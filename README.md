Notes on papers I read. 

To create symlink for setting up a new paper:

```
chmod +x papernote.sh
sudo ln -s papernote.sh /usr/local/bin/papernote
```

Starting a new note:

```
papernote GaLore https://arxiv.org/pdf/2403.03507
```

The title comes from the filename and goes in the header alongside the link and date, which is what the blog reads. Edit it there if the paper goes by a different name.
